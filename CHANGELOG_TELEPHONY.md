# Лог изменений модуля телефонии и AI-скоринга (Insurvoice.ai)

## 27 октября

### 1. Внедрена официальная матрица Insurvoice AE Sales Call Scorecard v1.0
- **7 секций и 26 чекпоинтов (`Y / N / N/A`)**: полный перенос официальной рубрики (Workbook v1.2, калибровка Kyle & Adithya) в модуль аналитики звонков.
- **Точная формула расчёта `60 / 40`**:
  - `60%` веса секции — доля выполненных применимых чекпоинтов (`Y / Applicable`).
  - `40%` веса секции — оценка качества секции по шкале `1–5` (`(Rating - 1) / 4`).
- **Правило доказательств (Evidence Rule)**: каждый из 26 чекпоинтов сопровождается цитатой или таймкодом из стенограммы разговора. Если прямого подтверждения в тексте нет — ставится `N`.
- **Грейды качества (Score Bands)**:
  - `85–100`: **Strong (Сильный)**
  - `70–84`: **Solid (Хороший)**
  - `55–69`: **Needs Coaching (Коучинг)**
  - `< 55`: **Priority Focus (В разбор)**

### 2. Автоматическое определение типа звонка и динамических весов
- ИИ самостоятельно определяет тип звонка по содержанию разговора:
  - `Confirmation / Pre-Call` — короткий звонок для подтверждения времени встречи в Google Meet и базовой пред-квалификации.
  - `Discovery` — первичная квалификация и выявление болей без демонстрации продукта.
  - `Demo` — демонстрация продукта по уже выявленным болям.
  - `Discovery + Demo` — полный цикл звонка (квалификация + боли + демо + закрытие).
  - `Follow-up / Close` — повторный звонок для разбора возражений и закрытия сделки в оплату.
- Для коротких звонков-подтверждений (`Confirmation / Pre-Call`) и звонков с начинающими агентами без действующей базы (прецедент `C-002`) этапы расчёта 12-месячных потерь, демо и закрытия в оплату автоматически получают статус `N/A` и не штрафуют менеджера.

### 3. Защита от оценки автоответчиков (Voicemail), ИИ-секретарей и коротких сбросов
- Звонки длительностью менее 20 секунд, попадания на голосовую почту (`Voicemail`) и ИИ-фильтры вызовов (`Record your name and reason for calling...`) автоматически получают статус **`N/A` («Автоответчик / ИИ-ассистент»)**.
- Даже если менеджер наговорил голосовое сообщение после сигнала автоответчика, вызов не оценивается по скрипту продаж и не занижает средний балл менеджера в таблице лидеров.

### 4. Единый редактируемый скилл `SKILL.md`, локализация `RU / EN` и переход на GPT-6.1 Terra
- Анализ звонков переведён на семейство моделей **GPT-6.1 Terra** (рекомендуемая) и **GPT-6 Luna** (эконом).
- Файл скилла `.agent/skills/insurvoice-call-scorer/SKILL.md` сделан единым источником правил для оценки звонков и выведен для чтения и редактирования прямо в админ-панель (кнопка **«Сценарий и критерии GPT»**).
- Добавлен переключатель языка **`RU | EN`** в шапке страницы: полностью переводит интерфейс телефонии, названия всех 7 секций и 26 чекпоинтов матрицы, а также задаёт язык генерации нового AI-разбора звонка от GPT.

### 5. Стабилизация синхронизации Quo, мультизадачность оценки и графики по дням
- **Параллельная оценка звонков (`/api/telephony/analyze`)**: можно запускать AI-оценку сразу у нескольких звонков подряд — каждый звонок обрабатывается параллельно со своим независимым индикатором без остановки предыдущих задач.
- Устранена проблема «прыгающих цифр» при нажатии **«Синхронизировать звонки»**: добавлен автоматический повтор запросов при лимите `429 Too Many Requests` со стороны Quo API и слияние (`merge`) звонков с базой Supabase без потери ранее загруженных записей.
- Под каждой из 5 верхних карточек KPI добавлена кнопка **«Показать график»** с визуализацией динамики по дням.
- В карточке разбора звонка рядом с кнопкой **«Переоценить»** добавлена кнопка **«Убрать оценку»**, а также исправлена автоматическая подгрузка аудиоплеера записи разговора для уже оценённых звонков.
